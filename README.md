# ลดทีละด่าน

เว็บแอปช่วยลดน้ำหนักแบบใช้ทุกวัน ติดตั้งลงหน้าจอโฮมของ iPhone ได้ และใช้งาน offline ได้

## ฟีเจอร์
- **ตั้งค่า 5 ขั้น:** ข้อมูลพื้นฐาน เวลาตื่น-นอน การออกกำลังกาย และจุดที่ต้องระวัง
- **วันนี้:** เช็กลิสต์ตามเวลาจริง แก้วน้ำ โปรตีนรายมื้อ ท่าเวทของวัน อารมณ์และโน้ต ความต่อเนื่อง 🔥 และ manifest ประจำวัน
- **แผน:** เป้าแคลอรี่ น้ำ โปรตีน ก้าวเดิน บันไดสู่เป้าหมายทุก 5 kg ตารางรายวัน แผนโปรตีน แผนเวท แผนคาร์ดิโอ (ชีพจร Zone 2 นาทีต่อสัปดาห์ และเพิ่มขึ้นทีละ 5 นาทีเมื่อทำครบ) และส่งแจ้งเตือนเข้า Calendar ของ iPhone
- **สัปดาห์:** เช็กอินทุกวันอาทิตย์ ระบบปรับแผนตามกฎ พร้อมรายงานว่าตัดสินใจอย่างไร
- **รายเดือน:** สรุปทุก 4 สัปดาห์ ปฏิทินความสม่ำเสมอ รอบเอว และโฟกัสของเดือนหน้า
- **ของฉัน:** สติกเกอร์สะสม การ์ดลงสตอรี่ แก้ไขข้อมูล
- **manifest ของตัวเอง:** ผู้ใช้เขียนประโยคให้กำลังใจเอง เลือกแสดงเฉพาะของตัวเองหรือผสมกับของแอป
- **ซิงก์ Apple Health:** Shortcut ดึงน้ำหนัก ก้าวเดิน น้ำ พลังงาน และวง Exercise กับ Stand จากแอป Fitness 14 วันล่าสุด แล้วส่งเข้าแอปผ่านคลิปบอร์ดหรือลิงก์ `#sync=` ไม่ต้องมี server
- **สำรองและกู้คืนข้อมูล:** บันทึกไฟล์สำรองลง Files หรือ iCloud Drive แล้วกู้คืนได้เมื่อเปลี่ยนเครื่องหรือลบไอคอน
- **สองภาษา:** `index.html` (English เป็นค่าเริ่มต้น) และ `th.html` (ไทย) ใช้ข้อมูลชุดเดียวกัน และจำภาษาที่เลือกไว้

## ความเป็นส่วนตัว
ไม่มี server ข้อมูลทั้งหมดเก็บใน browser ของผู้ใช้ (localStorage) ไม่ถูกส่งออกไปที่ใด

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปภาษาอังกฤษ (หน้าเริ่มต้น) |
| `th.html` | ตัวแอปภาษาไทย |
| `en.html` | ลิงก์เก่า พาไปหน้า index.html |
| `sw.js` | ให้ใช้งาน offline ได้ เปลี่ยนเลขเวอร์ชันในไฟล์ทุกครั้งที่อัปเดต |
| `manifest.webmanifest` | ชื่อและสีเวลาติดตั้งลงหน้าจอโฮม |
| `smile-180.png`, `smile-192.png`, `smile-512.png`, `smile-maskable-512.png` | ไอคอนแอป (ดาวยิ้ม ✦ พื้นดำ) |

แผนในแอปเป็นแนวทางทั่วไป ไม่ใช่คำแนะนำทางการแพทย์
